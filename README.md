# .github

This repository contains global configuration for my GitHub account.

## Contents

- **profile/** – public GitHub profile (profile/README.md)
- **workflows/** – shared GitHub Actions workflow templates
- **ISSUE_TEMPLATE/** – issue templates
- **PULL_REQUEST_TEMPLATE.md** – pull request template
- **CODEOWNERS** – code ownership and required reviewers

## Purpose

The goal of this repository is to unify:

- repository standards,
- CI/CD workflows,
- issue and PR structure,
- auditability and consistency across projects.

It serves as a central place for shared GitHub metadata.
